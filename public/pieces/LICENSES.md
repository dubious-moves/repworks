# Piece sets

The piece sets offered in Settings besides cburnett (chessground's own, by Colin M.L. Burnett,
GPLv2+). Each is the Lichess set of the same name, from
[lichess-org/lila](https://github.com/lichess-org/lila/tree/master/public/piece), unchanged,
under its own licence as lila's COPYING.md lists it.
